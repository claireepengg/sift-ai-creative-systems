# Visual assets to add

The repository is intentionally text-light on implementation details. The visuals should make the case study feel like creative technology rather than backend documentation.

Add images here using these filenames if possible:

## `hero.jpg`
Best single example.

Recommended composition:
- user or person reference
- scene reference
- product reference
- final generated image

A simple 3- or 4-panel layout is ideal.

## `workflow.jpg`
A visual progression showing selected stages of one generation.

Do **not** label proprietary methods or expose the exact internal sequence.

Use broad labels such as:
- Input
- Generation
- Refinement
- Final

## `app.jpg`
Screenshot of Sift in the iOS product experience.

Redact:
- personal email addresses
- internal IDs
- private user information

## `qc-review.jpg`
Screenshot of the internal quality-review interface.

Redact:
- usernames or emails
- user IDs
- database IDs if sensitive
- internal URLs
- private product metadata

## `outputs.jpg`
A small grid of strong final generations.

Choose 4–8 images that show:
- visual consistency
- different scenes
- different products
- believable results

## Suggested README image syntax

```markdown
![Sift — personalized AI fashion imagery](assets/hero.jpg)
```

and:

```markdown
![Sift quality review interface](assets/qc-review.jpg)
```

The strongest public version probably needs only 3–5 images total.
