# Public case-study scope

This repository is intentionally limited to portfolio-safe material.

It should **not** contain:

- production source code
- API keys or environment files
- cloud infrastructure details
- database hosts, credentials, or schemas beyond generic descriptions
- private model prompts
- proprietary evaluation logic
- internal scoring thresholds
- private user data
- production logs
- detailed model-routing logic

If a new file is added later, review it against this list before publishing.
