# Public repository scope

This repository contains portfolio-safe material only.

The production Sift codebase is private. Do not add:

- production source files
- API keys or `.env` files
- hostnames, bucket names, or internal URLs
- production database schemas or credentials
- private model prompts
- model-routing rules
- proprietary evaluation or scoring logic
- image-correction implementation details
- user data or production logs

The files in `examples/` are simplified, redacted examples based on engineering patterns used in Sift.
