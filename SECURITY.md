# Public case-study safety

This repository is intentionally **not** the production Sift repository.

Before publishing any additional code or screenshots, remove:

- API keys, tokens, credentials, cookies, and authorization headers
- database hosts, usernames, passwords, internal table dumps, or connection strings
- cloud bucket names and infrastructure identifiers
- private endpoint/domain details that do not add portfolio value
- user emails, names, IDs, photographs, or other private data without permission
- raw production prompts that you consider proprietary
- logs containing user data or signed media URLs

Prefer small, rewritten excerpts that demonstrate the design pattern over copying complete production modules.
